# The tour of the app.
#
# The points are for a screen of 1080 wide and 1920 high. They are scaled to
# the screen of the device that is used, so the same tour works on any phone.
#
# A step is one of:
#
#   tap    X Y   [name]        a tap on a point of the screen
#   taptext  words [name]      a tap on the text that is shown
#   swipe  X1 Y1 X2 Y2 [ms] [name]   a swipe from one point to another
#   text   words              typing into the field that is open
#   key    KEYCODE            a key, e.g. BACK, ENTER
#   shot   name               a picture without touching the screen
#   wait   seconds            a pause
#
# The tour walks what the app shows without an account, because a tour is run
# by a machine that has no key and must never be given one: the first screen,
# the account sheet, the sign-in dialog, settings and the themes. The parts that
# need a GitHub account — projects, sync, history — are the operator's to walk
# on a real install.
#
# The taps are done by name wherever the app gives a name, because a name keeps
# working when the layout moves. The two icons have no name on screen, so their
# points are used.

# --- the first screen, with nobody signed in ---
shot 01-sign-in
wait 2

# --- the account sheet, from the menu beside the title ---
tap 60 110 02-account-sheet
wait 3

# --- adding an account asks for a key ---
taptext "Add" 03-sign-in-dialog
wait 3
key BACK
wait 2
key BACK
wait 2

# --- settings, from the gear in the corner ---
tap 1010 110 04-settings
wait 3
shot 05-settings-top

# --- the theme swatches are a row below the account ---
swipe 540 1500 540 600 500 06-scroll-to-themes
wait 2
shot 07-themes
