# The tour of the themes.
#
# This tour takes a picture of the SAME screen in every theme, so that the
# pictures can be compared with each other. That comparison is the only way to
# find out whether a theme was applied at all: the names of the things on the
# screen are identical in every theme, because a theme changes colours and
# nothing else.
#
# The steps that only move the app to the settings are named "none", so that
# they take no picture and no number is used up. Every picture in the folder is
# therefore a theme, which is what tools/check-pixels.py --themes expects.
#
# Run with:    TOUR_FILE=tools/theme-tour.txt
# Checked by:  tools/check-pixels.py --themes <the folder of the pictures>

wait 2

# The gear in the top bar.
taptext "Settings" none
wait 3

# The themes are further down the settings, so they are scrolled into view.
swipe 540 1500 540 700 400 none
wait 2

# --- the five themes, one after the other ---
# The rest of the screen never changes, so any difference between the pictures
# is the theme and nothing else.
taptext "Milk" 01-milk-light
wait 2

taptext "Caramel" 02-caramel-light
wait 2

taptext "Gold" 03-gold-light
wait 2

taptext "Brownie" 04-brownie-light
wait 2

taptext "Dark Chocolate" 05-dark-chocolate-light
wait 2

# --- the dark side of the same five ---
# The same screen, the same theme order, with the dark variant switched on.
# The switch stays on for the rest of the tour, so it is only pressed once.
taptext "Dark variant" none
wait 2

taptext "Milk" 06-milk-dark
wait 2

taptext "Caramel" 07-caramel-dark
wait 2

taptext "Gold" 08-gold-dark
wait 2

taptext "Brownie" 09-brownie-dark
wait 2

taptext "Dark Chocolate" 10-dark-chocolate-dark
wait 3
