## #42 is the one that stays open

`text selection is broken for user messages`. Text selection is a platform long-press gesture and
Robolectric does not perform it, so **no test in this suite can say whether it works**. What was done is
the one structural change that can be justified: `animateContentSize()` was on the operator's bubble,
where the height can never change, and it is a layout modifier that re-lays out on every pass. The
agent's bubble keeps it, because there the animation is real.

If selection is still broken on the next build, this was not the cause. The trace will need to say what
was on screen and what the gesture did.
