## The order it was done in, and why that order

Sorted so nothing waited on something later.

1. **R1 — selectable text** (`f5156a5`). Asked twice, and the reason is plain: the app reports things
   a person then wants to send somewhere.
2. **R9 + R10 — the session log's label and unit** (`0b1bb93`). "The record" became "Session log", and
   the limit became tokens summed from the `size` column the record already keeps.
3. **The footer's context word** (`be187fc`), and **R11 — the size memo** (`fef513e`). The memo is
   keyed by the file's length *and* mtime, because either alone misses a case.
4. **R25 — reset** (`6ebc015`). It could only be written after the defaults were one statement each,
   which is why it came after R10 changed one of them.
5. **R22, R24, R23 — the settings screens** (`1053cf7`, `b672628`, `5c0d370`). All three were "the
   screen asks for the wrong thing", and two of them were the *same* dialog used for a different
   question.
6. **R4 — the context's four numbers** (`90c67c2`). It reads markers the acts already write, so it
   could only be built once the distinction between compaction and trimming was settled — which is
   what R10's unit change made thinkable.
7. **R19 — the local↔synced cycle** (`5e4745c`), with the licence question that publishing raises.
8. **R26 — the themes** (`fc7c0f6`). Last because it is the only one where the app was doing what it
   said and the complaint was still true: five palettes, all brown.

## Two things worth keeping

**Three reports were "the app did the thing but said nothing useful".** The 400 hid its reason behind
OpenRouter's wrapper sentence, the lock icon was `Info` because the real one was in a dependency the
app does not carry, and the chat drew a shape the operator had not asked for while a document said it
was done.

**And four tests passed while the app was wrong**, each for the same reason: they asked whether
something existed rather than whether it was right.

| Test | Passed | Was wrong because |
|---|---|---|
| `no two themes are the same palette` | yes | it compared for *equality*, and five browns are five different colours |
| `AgentToolsTest` (absent) | — | nothing asserted a tool schema *was* a schema, so eleven bare examples shipped |
| the trim's budget | yes | it asserted the record fits the limit, but the newest burst is never dropped |
| `every bubble has a footer` | yes | it read the model, not the screen |

The counter-example is the same file that found two defects on its first run: ask what the result
*is*, not whether the code is there.
