## The order of work from here

Sorted so that nothing waits on something later. Each is small and independently shippable.

1. **R1 — selectable text.** `SelectionContainer` over the text-heavy screens. Asked twice.
2. **R9 — "The record" → "Session log".** One label, and the operator asked directly.
3. **R10 — the session limit in tokens, default 10,000,000**, dropping the MB and line limits. The
   behaviour is the trim, which already works per burst; this is the unit.
4. **R11 — cached sizes.** Running totals per file in the app's flags directory, with length+mtime
   beside them so an out-of-band edit is detected. Depends on R10's unit.
5. **R4 — the context block's four fields**, which depend on knowing what compaction and trimming
   each did. Compaction is the agent's `forget`; trimming is the app's. The record already
   distinguishes them by `ctx` and by the `trimmed` note.
6. **Footer's context word** — small, and it makes the forgetting visible.
7. **R22 — the key state not refreshing** after a save. A re-read, not a redesign.
8. **R24 — the effort popup** with one select.
9. **R23 — the provider picker** listing the model's providers.
10. **R25 — reset to defaults**, which needs one `Defaults` object so there is one statement of each
    number rather than a second copy that drifts.
11. **R26 — themes**, which needs the operator to say what "truly different" means before it is worth
    guessing at.
12. **R19 — the local↔synced cycle.** The largest: `add to GitHub` plus `keep as local`, and it is a
    git operation with a confirmation that says what it does to the remote.

## Closed, with the note that matters

**R27's real cause was not the chat.** Every tool schema was a bare example — `{"ids":"2 5 7-12 14"}`
— with no `"type":"object"`, so DeepSeek refused the whole request before reading a message. The
tools ride on every request, so no message could have worked. The provider's real sentence sat in
`error.metadata.raw`, one level below what `why()` read, which is why every failure printed the same
three useless words.

And the new `AgentToolsTest` found a **second** defect on its first run: `edit` reads seven arguments
and its example showed three, so `from`/`to`, `at` and `text` were never offered to the model.
